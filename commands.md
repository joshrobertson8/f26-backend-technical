# Commands

Run setup from this folder and choose a language from the menu.
It installs and checks only that option. Internet access is required.
Installing a C compiler may ask for administrator access.

The options are Python (FastAPI), JavaScript (Express), TypeScript (Express),
JavaScript (Next.js), TypeScript (Next.js), Java (Spring Boot), and C.
Python is installed if needed because the setup and test runner use it.

macOS / Linux (Bash or Zsh):

```sh
./setup/setup.sh
```
